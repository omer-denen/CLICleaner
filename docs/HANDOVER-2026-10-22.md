## 3. Sonraki oturum — T69 adım adım

> Amaç: “kullanıldı” demek için gerçekten kullanım kanıtı; “bilinmiyor” ile
> “hiç kullanılmadı”yı ayırmak.

### F1 — Observer hijyeni (önce bu)

- `src/core/cli-inventory.ts`:
  - `scanStandaloneShims`: `readExeInfo(p)` öncesi `stat` (atime+mtime) al;
    okuma sonrası `utimes` ile geri yaz.
  - `annotateHealth`: stub `.exe` okumalarında aynı koruma.
  - Ortak yardımcı: `withPreservedAtime(path, fn)` (hata durumunda sessiz geç).
- `src/core/exe-info.ts` / `node-runtimes.ts`: okuyan taraflar aynı yardımcıyı
  kullanabilir; kullanım kararı yoksa da metadata hijyeni korunur.
- Kabul: iki ardışık envanterde aynı aracın atime’ı değişmiyor; test.

### F2 — Durum klasörü kanıtı

- `findStateDirs`: `%LOCALAPPDATA%\Programs\<ad>` adayını çıkar.
- `boundedStats`: `logs/`, `*.log`, `*.jsonl`, `*.tmp`, `cache/` altını atla;
  yalnızca config/state/db dosyalarını say.
- Kabul: `windows-mcp` yalnızca log yazdığı için “Yakında” olmuyor.

### F3 — `usageVerdict` karar kuralları

- Atime **tek başına** `recent` üretmesin; en az bir doğrulayıcı sinyal
  (geçmiş/gerçek durum/çalışan süreç) aransın.
- `lastAccessAt` ile `installedAt` arası ≤2 sn ise atime’ı yok say.
- Toplu atime: 5 sn içinde ≥3 farklı komut aynı atime → atime’ı kanıttan çıkar;
  kanıta “toplu okuma olabilir” notu.
- Geçmiş tek başına `recent` üretmesin; “kullanıldı, zaman bilinmiyor” →
  `unknown` + düşük/orta güven.
- Çalışan süreç varsa “Atıl” deme; `unknown` + “şu an çalışıyor” kanıtı.
- Kabul: crewai/vpk/dotnet-script → Atıl/Bilinmiyor; opencode2 → Bilinmiyor;
  windows-mcp → Bilinmiyor (çalışıyor); claude → Bilinmiyor.

### F4 — Kabuk geçmişi ayrıştırıcısı

- `findHistoryMentions` paket çalıştırıcıları:
  - `npx` / `pnpx` / `bunx` / `uvx` / `pipx run` + paket
  - `pnpm` / `yarn` / `bun` + komut (`exec`/`run` dahil)
  - `dotnet tool run <komut>`
- `install` / `add` / `remove` / `update` / `upgrade` komutlarını **kullanım
  sayma**.
- Pozitif test: `npx @deepseek-ai/dsh web`, `pnpm dsh web`.
- Negatif test: `npm install -g dsh`, `pnpm add dsh`.
- Kabul: `dsh` artık “Atıl” değil; en azından “kullanıldı, zaman bilinmiyor”.

### F5 — Arayüz / kanıt görünürlüğü

- `web/src/screens/Tools.tsx` + i18n: durum yanında **kanıt türü** göster:
  “geçmişte var (tarih yok)”, “toplu okuma”, “çalışıyor”, “kurulum anı”.
- `unknown` metnini “Bilinmiyor” olarak koru; “Atıl”dan ayır.
- Gerekirse `CliTool`’a `usageEvidenceKind` / `atimeSuspect` alanları ekle
  (sözleşme + UI).
- Kabul: kullanıcı neden “Yakında/Bilinmiyor/Atıl” gördüğünü okuyabiliyor.
